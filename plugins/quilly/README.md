# Quilly for Claude Code

Gives Claude read access to the Google Meet transcripts recorded by the
[Quilly](https://github.com/gegham-khachatryan/quilly) Chrome extension: list and search meetings, read a
transcript, and follow the call being recorded as people speak. The extension answers each request
from its own database over localhost, so nothing is exported and nothing leaves your computer.

The plugin runs [`quilly-mcp`](https://github.com/gegham-khachatryan/quilly/tree/main/packages/quilly-mcp),
the MCP server the extension pairs with. Node.js 20 or newer is required.

## Install

1. In Chrome open Quilly → Settings → **Local agents** and switch on *Allow local agents to read
   transcripts*. Copy the pairing token shown there.
2. Add the marketplace and install the plugin from a Claude Code session:

   ```
   /plugin marketplace add gegham-khachatryan/quilly
   /plugin install quilly@quilly
   ```

   Claude Code asks for the pairing token and keeps it in the system's credential store. Leave the
   port as it is unless you changed it in Quilly's settings. `/plugin configure quilly@quilly` opens
   the same dialog again.

## Tools

| Tool | What it does |
| --- | --- |
| `list_sessions` | Sessions newest first, filtered by text, participant or status. |
| `get_session` | A session's transcript as text, Markdown or JSON, with a cursor for live follow-up. |
| `wait_for_updates` | Blocks until a recording session gains new or changed entries, then returns them. |
| `search_transcripts` | Entries containing a phrase, across all sessions or one, optionally for a single speaker. |

All tools are read-only. Agents cannot start, stop, rename or delete recordings.

## Privacy

The server binds `127.0.0.1` only, and both sides prove they hold the pairing token before any data
is exchanged. See the [privacy policy](https://gegham-khachatryan.github.io/quilly/privacy).

The plugin manifest and the icon in this folder are generated by `npm run listings -w quilly-mcp`;
edit `packages/quilly-mcp/src/listings.ts` instead.
